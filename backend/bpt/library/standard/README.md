# Biblioteka standardowa

Biblioteki dostarczane z programem (tylko do odczytu), w formacie bibliotek użytkownika
(`Library` w `bpt/library/libraries.py`). Identyfikatory symboli zaczynają się od `std:`.
Modele robimy sami z publicznych not katalogowych (faza 6, FR-LIB-3) – każdy z testem
porównującym z notą.
